Résultats clés : CA +3,9 % (110 000 € pour 112 000 € visés, −2 000 €), porté par le trafic (+8,1 %) alors que le taux de transformation baisse (27 % → 25 %, −3 pts vs objectif). Contrôle : tickets × panier moyen = CA réel pour août et septembre.
