# Fiche de révision RCN : le site web

## 1. Un site web, c'est quoi pour une entreprise ?
| Rôle | Exemple |
|---|---|
| **Outil de communication** | Diffuser un catalogue produit |
| **Outil au service d'une stratégie** | Accroître le chiffre d'affaires (CA) |
| **Commercial virtuel présent 24h/24, 7j/7** | Une boutique en ligne |

**Les objectifs possibles :** développer sa notoriété et sa crédibilité · se mettre en valeur (portfolio) · présenter ses produits ou services (catalogue) · vendre · promouvoir un événement · améliorer le service client.

**3 grands objectifs des sites commerciaux :** **Visibilité · Vente · Engagement** (un site peut en viser plusieurs).

**Avant de créer un site, on définit 4 choses :**
1. les **objectifs** du site
2. les **cibles** à atteindre
3. les **informations** que cherchent les clients potentiels
4. les **services** à leur offrir

## 2. Les 5 types de sites web
| Type | Objectif | En bref | Mise à jour | Exemple |
|---|---|---|---|---|
| **Site vitrine** | **Présenter** | Carte de visite : image de l'entreprise, produits/services | **Très rarement** | Site d'un artisan |
| **Blog** | **Informer** | Articles publiés dans l'ordre chronologique, capter une audience, attirer du trafic qualifié, montrer son expertise | Très souvent | Blog de conseils |
| **E-commerce (marchand)** | **Vendre** | Boutique virtuelle ouverte 24/7, élargir sa clientèle | Très souvent | Amazon |
| **Communautaire** | **Créer une communauté (partager)** | Échanger conseils et avis entre internautes | Très souvent | BlaBlaCar, Instagram |
| **Application web** | **Travailler ou s'amuser** | Programme qui tourne dans le navigateur, sans installation, services centralisés, maintenance facile | — | Plubel, Canva |

Point commun à tous : **rendre l'activité accessible au plus grand nombre**.

> Astuce : le **vitrine** est le seul mis à jour **très rarement**.

## 3. Web ≠ Internet (question classique !)
- **Internet** = le **réseau** informatique mondial : des réseaux interconnectés qui permettent aux ordinateurs, serveurs et équipements de communiquer.
- **Le Web** (World Wide Web, WWW = « toile d'araignée mondiale ») = **un des services** d'Internet (le plus connu) : un ensemble d'informations **reliées par des liens hypertextes** et organisées en sites.

**Internet ce n'est PAS que le Web.** Les services et leurs protocoles :
| Service | Protocole(s) |
|---|---|
| Web | HTTP, HTTPS |
| Mail | SMTP (envoi), POP, IMAP (réception) |
| Transfert de fichiers | FTP |
| Session à distance | SSH |

**Ce qu'on trouve sur le Web :** documents, images, audio, vidéos, documents et applications interactifs.

## 4. Les 3 couches du Web (l'iceberg)
| Couche | Part | Contenu |
|---|---|---|
| **Web de surface** | 5 à 10 % | Indexé par les moteurs : Wikipédia, Google, YouTube, e-commerce |
| **Deep Web** | 90 à 95 % | Privé ou non indexé : extranets, données de recherche, forums privés, cloud, messageries |
| **Dark Web** | ≈ 0,01 % | Anonyme, accès via **Tor**, sites en **.onion** (Hidden Wiki, Torch, SecureDrop, ProPublica) |

## 5. Les moteurs de recherche
**Exemples :** Google, Bing, Yahoo, DuckDuckGo, Qwant.

**A. L'indexation (le moteur construit sa base) :**
1. Des **robots** (crawlers) parcourent le web de page en page en suivant les liens hypertextes.
2. Chaque page contient des **mots-clés** qui décrivent son contenu.
3. Les pages, sites et mots-clés trouvés sont **classés dans une base de données** (on parle d'**indexer** / **référencer** un site).

**B. Une recherche :**
1. L'internaute envoie ses **mots-clés**.
2. Le moteur les **compare** aux mots-clés indexés.
3. Des **algorithmes** analysent la **pertinence** de chaque page.
4. Les pages sont proposées, **triées par qualité et pertinence**.

**Schéma :** Mots-clés → Navigateur → Moteur de recherche (classement) → Résultats → Navigateur

| | SEO | SEA |
|---|---|---|
| Résultats | **Organiques** (naturels) | **Sponsorisés** |
| Prix | Gratuits | **Payants** (publicité) |

## 6. L'adresse web (URL)
Chaque ressource web (page, fichier, image, vidéo) a une **adresse unique : l'URL**, qui commence par `http://` ou `https://`.

**Décomposer une URL :** `https://plubel-prod.ube.fr/my/courses.php`
| Partie | Nom |
|---|---|
| `https` | **Protocole** (le S = sécurisé) |
| `plubel-prod` | **Sous-domaine** |
| `ube.fr` | **Nom de domaine** (`.fr` = extension) |
| `/my/courses.php` | **Arborescence** (chemin de la page) |

## 7. Site web, page web, navigateur
- **Site web** = ensemble de **pages web reliées entre elles**, accessibles depuis une **même adresse (URL)**. Contient textes, images, vidéos.
- **Page web** = document codé en **HTML + CSS + JavaScript**, affiché par un **navigateur**.
- **Navigateurs :** Google Chrome, Safari, Mozilla Firefox, Microsoft Edge, Opera, Brave.
  ⚠️ Ne pas confondre **navigateur** (Chrome) et **moteur de recherche** (Google).

| Langage | Rôle | Image pour retenir |
|---|---|---|
| **HTML** | **Structure** le contenu (textes, images, liens, sections) | Le squelette |
| **CSS** | **Mise en forme** (couleurs, polices, positions) | Les vêtements |
| **JavaScript** | **Interactivité** | Les muscles |
