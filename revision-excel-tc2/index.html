Étape 2 · J2

Retrouver le HT à partir du TTC

Colonne J « Montant mensuel HT »

On connaît le TTC (colonne M) et le code TVA (colonne K). Le taux est dans la feuille TVA : code 1 = 5,5 % (C3), code 2 = 10 % (C4), code 3 = 20 % (C5). On divise, on ne multiplie pas : HT = TTC ÷ (1 + taux).

J2 · SI imbriqués

    
J2 · version plus courte (bonus)



    
Pourquoi les $ ?Quand tu tires la formule vers le bas, K2 devient K3, K4… (c'est voulu) mais le taux doit rester C3. $C$3 bloque la colonne et la ligne. Raccourci : F4 pendant que le curseur est sur la référence.

O2 · 5 SI pour 6 tranches



    
La règle des SI imbriquésOn monte les tranches dans l'ordre, toujours avec <. Excel s'arrête à la première condition vraie, donc pas besoin d'écrire « entre 10 000 et 15 000 ». Nombre de SI = nombre de tranches − 1. Nombre de parenthèses à la fin = nombre de SI.

Le jour du contrôle

  
L'exemple de jeudi aura d'autres chiffres, d'autres noms ou d'autres tranches, mais la méthode reste la même.

  
    
    
  • 1Lire tout le sujet et repérer les feuilles de paramètres (comme TVA). Tout taux qui vient d'une autre feuille = référence avec $.
    • 
    
  • 2Copier la feuille de base avant chaque exercice (Déplacer ou copier › Créer une copie), et la renommer exactement comme demandé.
    • 
    
  • 3Écrire la formule en ligne 2, vérifier sur 1 client à la calculatrice, puis double-clic sur la poignée pour recopier.
    • 
    
  • 4Tranches : compter les tranches, écrire tranches − 1 SI, toujours avec < dans l'ordre croissant.
    • 
    
  • 5Sous-totaux : trier d'abord. 2ᵉ et 3ᵉ sous-total : décocher « Remplacer ».
    • 
    
  • 6TCD : Moyenne/Max/Min dans « Paramètres des champs de valeurs », % dans « Afficher les valeurs ».
    • 
    
  • 7Mettre les formats à la fin : € (Comptabilité) et % là où il faut.
    •
